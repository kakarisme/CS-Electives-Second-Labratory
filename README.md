# Adaptive Coding Environment

## Project Description

This project is a prototype of an adaptive coding environment based on user modeling and K-Means clustering.

The user model was developed using selected features from the Stack Overflow Developer Survey 2025.

## User Profiles

The system uses two user profiles:

### Cluster 0 – The Established AI-Aware Developer

This profile represents users with broader technical experience, higher AI usage, and greater interaction with programming languages, databases, and development environments.

### Cluster 1 – The Emerging AI-Curious Developer

This profile represents users with less technical diversity and lower overall interaction with AI-assisted development tools.

## Adaptive Features

The prototype adapts the coding environment based on:

* Education Level
* Developer Type
* Current Programming Languages
* Desired Programming Languages
* Current Databases
* Desired Databases
* AI Usage
* AI Frustration
* Human Help Preference
* Development Environments

## Technologies Used

* HTML
* CSS
* JavaScript
* GitHub
* GitHub Pages

## Purpose

The purpose of the prototype is to demonstrate how a user model can influence the behavior of an adaptive coding environment.

Users can switch between Cluster 0 and Cluster 1 to observe how the system changes its recommendations, explanations, AI assistance, and learning resources.

## Dataset

The project is based on selected features from the Stack Overflow Developer Survey 2025.

The clustering and user-profile analysis were performed before the development of this prototype.
